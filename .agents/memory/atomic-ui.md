---
name: ATOMIC UI
description: Product-design rule for presenting the L0–L9.5 learning journey without exposing engine complexity.
---

ATOMIC UI is the required interaction model for the L0–L9.5 learning journey. “L” means Learning. Each stage is a full-page cockpit that clearly shows where the user came from, what they are doing now, and where they are going next.

Every stage provides top-level journey progress, document upload access, document download access, and one relevant connected standalone feature. The full feature inventory remains available through progressive disclosure rather than competing with the current task.

**Why:** The user wants the product to feel like a clear car cockpit while complex scoring, evidence, marketplace, billing, and orchestration systems remain under the hood.

**How to apply:** Give each stage one dominant action, preserve real backend behavior, derive visual identity from the supplied ATANDA geometric logo palette, and keep advanced tools behind an explicit disclosure.
